# Durable lessons

Append only generalized, verified lessons. Do not store client content or temporary notes.

## 2026-08-23

- Key parity can pass while newly expanded source meaning is missing or truncated. Verify semantic coverage, not only file shape.
- Literal product nouns can accidentally create medical, bureaucratic, religious, or software-documentation language. Validate the target concept and register.
- A fluent invented slogan is not native evidence. Mark original constructions `ASSEMBLED` and support their components with real usage.
- A book is often the outcome, not the starting motive. Begin with the thoughts, memories, experience, knowledge, or story the person wants to express and pass on.
- Reusing the same emotional rhythm across locales produces template copy. Let each language choose its own information order, verbs, directness, and cadence.
- A second language model can call an idiomatic phrase good while it still begins from the wrong product artifact. Model review supplements, but never replaces, the human-truth contract and native-source evidence.
- A grammatically correct sentence can still expose its source-language skeleton through abstract noun lists, repeated possessives, and ownership formulas. Run a separate spoken-language pass that rewrites from meaning and names the person's real action.
- Conversational does not mean slang. Native syntax, ordinary collocations, clear actors, and varied breath make copy speakable without weakening precise interface or trust language.
- Some workflow runtimes do not support `import.meta`. Pass the references directory explicitly through workflow arguments.
- A large multi-locale review must survive time limits and transient gateway failures. Split calls into restartable chunks or use a runner with no session ceiling.
